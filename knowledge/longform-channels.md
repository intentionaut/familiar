# Longform channels

The scaffold the **long** branch of `repurpose` fills. One block per channel
that takes a longform companion piece. Short-form channels live in
`social-schedule.md`; this file is only for places a full piece goes.

Leave this file as the template if you have no second longform channel. The
long branch stops rather than guessing a form.

## The standalone rule

For any channel where the reader has not read the source piece, the companion
must make sense on its own. It is not bonus features for a film nobody watched.
The making-of is the hook; the source piece is what they click through for.

Every stage after `repurpose` inherits this rule from the brief.

## What a companion is not

- Not a summary of the source piece.
- Not the source piece with a different intro.
- Not a list of things you learned, unless the piece earns that shape.

If the working files do not hold a real story about how the piece was made,
there is no companion this time. Skipping is allowed. A thin companion costs
more than a missing one.
