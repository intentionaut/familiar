Run the Familiar **inspire** command. Familiar lives at `{{FAMILIAR_HOME}}`.

1. Read `{{FAMILIAR_HOME}}/AGENTS.md` for the rules.
2. **Knowledge lives at `{{FAMILIAR_KNOWLEDGE}}`.** Every `knowledge/<file>.md` a prompt names is read from there, not from the Familiar folder.
3. Read `{{FAMILIAR_HOME}}/prompts/inspire.md` and follow every instruction in it exactly.
4. Arguments: $ARGUMENTS
5. Write the clip to the `inspirations/` folder next to the resolved knowledge folder.
