# Publication styles

These are templates for adapting Familiar to different kinds of publications.
Each one describes what to change in positioning, voice, and slot shapes, and
how to adapt the pipeline stages.

They are not stages. They are knowledge files that tell the existing stages
how to behave for your kind of publication.

## How to use one

1. Copy the style file to your `knowledge/` folder (or keep it here and
   reference it).
2. Follow its "What to change" section to fill in `positioning.md` and
   `voice-guide.md`.
3. If it suggests replacing or skipping stages, the pipeline will do that
   when you tell it to in your positioning file.

## Adding your own

If you have adapted Familiar to a different kind of publication, a short
style file helps the next person. Same rule as everything else: real
examples, no invented ones. See `CONTRIBUTING.md` for the full process.
